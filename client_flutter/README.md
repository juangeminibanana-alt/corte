# Corte · Flutter

Aplicación compartida para Android, Windows y web, conectada al backend existente en Firebase y Google Cloud.

Consulta [MIGRATION.md](MIGRATION.md) para conocer el alcance, las protecciones de datos y los comandos de compilación. La revisión de Flutter utilizada está fijada en [toolchain.lock.json](toolchain.lock.json).

La interfaz sigue el diseño Contraste TikTok Shop aprobado: navegación negra, contenido claro, coral y cian. Trabaja con las muestras, fotografías, variantes, videos y ventas reales de las API de Corte.
